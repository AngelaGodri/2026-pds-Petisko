## 🎯 Sobre o projeto
​
**Problema:A falta de ferramentas eficientes para buscar pets perdidos e gerenciar sua saúde centralizadamente gera atrasos e ineficiência nos cuidados animais. Uma plataforma integrada resolve isso ao unificar buscas por geolocalização, guias de serviços locais e uma carteirinha digital de saúde em um só lugar.
**Solução proposta:A solução proposta é o PETisko, um sistema web integrado que centraliza o gerenciamento da saúde animal, localização por mapa de serviços veterinários e pet shops, e suporte na busca por pets perdidos. Desenvolvido com base técnica sólida, ele resolve a dispersão de dados, otimiza o tempo de resposta em emergências e apoia a comunidade de tutores.
**Público-alvo:Tutores de animais
​
**Tecnologias (stack):HTML, CSS, JavaScript, Python, SQL, Flask, Bootstrap / Visual Studio Code, Git, GitHub, Navegador web (exemplo: Google Chrome), CloudflareP, Leaflet / Servidor local Flask (durante desenvolvimento), Hospedagem em nuvem (exemplo: Render), Banco de dados MySQL, Possuirá um sistema de mapa com o Leaflet, Possuirá hospedagem no Cloudflare.
